## What I'm Building

### RateMyTWU
A professor review and degree-planning platform for Trinity Western students. Existing platforms like RateMyProfessors barely cover TWU faculty, so students were relying on word of mouth to pick courses and professors — RateMyTWU fixes that with real, searchable reviews and ratings.

I built the FastAPI REST API over PostgreSQL, including a joined SQLAlchemy query that computes aggregate ratings and review counts per professor. Authentication runs on JWTs verified against Supabase's public JWKS endpoint on every request. The React frontend includes an interactive drag-and-drop degree planner (dnd-kit) with a Kanban-style board and persisted state across semesters, so students can plan their entire degree, not just leave reviews. The whole thing is deployed with a React frontend on Vercel, routed through Cloudflare DNS, and backed by GitLab CI running the test suite on every change.
